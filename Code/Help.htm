WebPhotoshop說明文件

      WebPhotoshop，是利用HTML5技術在Web上實現對圖形影像的處理，同時實現即時的多人協作處理圖形影像技術，構建易維護、易共享、易於拓展、即時性的Web圖形影像處理平臺。 功能主要包括：圖形繪製、影像處理、影像操作、多人協作操作影像、即時交流、圖片搜尋。

一、功能說明：

1、圖形繪製

      實現鉛筆、畫筆（書法畫筆、噴槍、蠟筆、記號筆、水彩畫筆）的繪製效果。實現直線、曲線、橢圓（圓）、矩形（圓角矩形）、三角形（直角三角形、等邊三角形、任意三角形）、多邊形的繪製。繪製過程中，可以選擇顏色，選擇顏色有兩種方式：顏色選擇、顏色拾取。可以進行顏色填充，即對選定區域，用選擇的顏色進行填充。

2、影像處理

      能夠實現的效果有：黑白、模糊、亮度/透明度、反色、霧化、銳化、浮雕、雕刻、柔化、油畫、積木、懷舊、蒙版，蒙版包括：紅色蒙版、藍色蒙版、綠色蒙版。

3、影像操作

      能夠對影像進行的操作有：影像選擇，包括區域選擇、物件選擇。影像移動，即對選擇區域或物件的移動。影像裁剪，包括矩形裁剪（保留裁剪區內、保留裁剪區外）。影像的旋轉，即將畫布或者選擇的區域物件向右90度、向左90度、180度、垂直旋轉、水平旋轉、任意度數。橡皮擦效果，能夠擦除繪製的影像。影像的縮小放大，包括影像的區域性縮放和影像的整體縮放。插入文本，即在影像上插入文本，能夠改變文本顏色、字型、大小，實現加粗、傾斜、下劃線、刪除線效果。將影像儲存為圖片。將影像存到伺服器。將影像另存新檔其他格式。影像儲存為下次可以再進行編輯的自定義格式。能夠實現多圖層，即新增圖層、刪除圖層、圖層層次改變。

4、多人協作操作影像

      實現多人線上協同繪製、處理影像。

5、即時交流

      在多人協同處理影像的過程中，參與協同作業的成員，能夠進行文本交流，即傳送和接收文字、表情、圖片，語音交流，影片交流，傳送截圖，抖動視窗，傳送檔案和接收檔案。還可以請求對方位置及地圖上顯示。交流過程中，可以建立組，進行群交流。

6、圖片搜尋

      搜尋伺服器上的圖片，點選圖片後，則可以進行圖片的編輯。

二、操作流程：

1) 進入系統後，顯示主工作區，包括選單欄、選項欄、工具箱、主畫板、歷史記錄、圖層管理。

2) 預設為鉛筆，可以在主工作區畫圖。可以選擇顏色等屬性。

3) 開啟圖片，進行圖片編輯。

4) 點選登入，進入線上協作，選擇加入組，或者新建組。
